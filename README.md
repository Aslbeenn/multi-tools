# أدواتي — Multi Tools

موقع أدوات متعددة باللغة العربية، يعمل بالكامل داخل المتصفح.

## الأدوات
- عداد الكلمات والأحرف
- تحويل حالة الأحرف
- مولد كلمات مرور
- آلة حاسبة
- حساب النسبة المئوية
- حساب العمر
- ضغط الصور
- صورة إلى Base64
- منسق JSON
- Unix Timestamp
- ترميز وفك ترميز URL
- HEX إلى RGB

لا يحتاج الموقع إلى خادم أو قاعدة بيانات.
